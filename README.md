# 📖 Hifz Al-Ankabut (حفظ سورة العنكبوت)

A dedicated, lightweight web application designed to assist with the memorization (*Hifz*) and study of Surah Al-Ankabut, featuring a clean and focused reading interface.

## 🌟 About The Project
**Hifz Al-Ankabut** is a single-file web tool built to make Quranic review and memorization easier, clearer, and accessible directly from any browser without complex setup.

## ✨ Features
- **Focused Quranic Text:** Clean typography tailored for readability and memorization tracking.
- **Single-File Solution:** Entirely self-contained within a single HTML file for instant loading and portability.
- **Zero Configuration:** No installation, databases, or local servers required—just open and use.
